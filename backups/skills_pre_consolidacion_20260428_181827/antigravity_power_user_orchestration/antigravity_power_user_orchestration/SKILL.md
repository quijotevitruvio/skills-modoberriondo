# Antigravity Power User Orchestration (Level 99)

Mastering the advanced features, tool orchestration, and context management of the Google Antigravity IDE for hyper-efficient engineering.

## 🧠 Advanced Context Management
- **Persistent Context Engineering**: Utilizing and maintaining the `persistent_context` to provide the model with a constant, high-fidelity world-view of your project.
- **Context Compaction**: Techniques for summarizing long interaction histories into dense "knowledge checkpoints" to maintain token efficiency without losing intent.
- **Selection Optimization**: Strategic file opening and focus to guide the model's primary attention toward relevant code paths.

## 🛠️ Tool & MCP Orchestration
- **Parallel Execution**: Orchestrating multiple background commands, browser sessions, and searches concurrently to eliminate wait times.
- **MCP Server Management**: Designing and deploying custom MCP servers to connect the IDE to specialized internal datasets or legacy systems.
- **Tool Chaining**: Combining the `read_url_content` with `view_file` and `terminal` to perform automated research-to-code cycles.

## 🚀 Efficient Navigation
- **Semantic Searching**: Leveraging `grep_search` and ripgrep to traverse massive codebases quickly before initiating edits.
- **Environment Tuning**: Optimizing local Ollama instances and development servers for maximum IDE responsiveness.
