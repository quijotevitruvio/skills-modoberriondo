# [EN] CLI Bash/Perl One-Liners

[EN] Powerful one-line commands for data manipulation and automation.


## ✂️ Text Processing
- **Sed & Awk Mastery**: Complex regex substitution and column-based data extraction.
- **Perl Power**: Using `perl -pe` for advanced multi-line replacements and mathematical transformations in streams.
- **Grepping with Intent**: Leveraging `pcregrep` and `ripgrep` for deep pattern discovery.

## ⚙️ System Automation
- **Looping & Mapping**: Using `xargs` and `parallel` to run single commands against thousands of files or URLs.
- **Pipe Orchestration**: Building long chains of commands (`|`) to transform raw logs into actionable CSV/JSON reports.

## 🛡️ One-Liner Security
- **Safe Execution**: Understanding the risks of "eval" and how to properly escape variables in one-liners.
- **Audit Trails**: Reading command history and reverse-engineering complex one-liners for reuse.
