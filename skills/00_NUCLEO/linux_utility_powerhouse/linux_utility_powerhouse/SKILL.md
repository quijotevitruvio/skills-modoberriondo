# Linux Utility Powerhouse (Level 99)

Mastering the foundational and modern utilities that form the backbone of a high-performance Linux environment.

## 🛠️ Data Wranglers
- **jq & yq**: Surgical extraction and transformation of JSON and YAML data.
- **csvkit**: Masterful handling of large CSV files from the terminal.
- **bat & fd**: Modern, high-performance alternatives to `cat` and `find`.

## ⚙️ Process & Resource Control
- **htop / btop / glances**: Real-time system monitoring and process prioritization (`nice`, `renice`).
- **lsof & netstat**: Identifying open files and network connections to debug resource leaks.
- **systemd mastery**: Managing services, timers, and logs (`journalctl`) at the enterprise level.

## ⚡ File System Mastery
- **rsync**: Advanced local and remote file synchronization with differential delta logic.
- **du / df / ncdu**: Visualizing and managing disk space usage with speed and precision.
