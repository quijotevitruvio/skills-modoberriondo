# Astro Expert Skill (Level 99)

The ultimate blueprint for ultra-fast, content-driven websites using the Islands Architecture.

## 🚀 Performance Foundations (Islands Architecture)
- **Partial Hydration**: Use `client:load`, `client:visible`, or `client:idle` to hydrate only the necessary components.
- **View Transitions**: Implement fluent page transitions without the SPA overhead.
- **Zero-JS by Default**: Target 100/100 Lighthouse scores by offloading logic to build time.

## 🛠️ Advanced Optimization
- **Image Service**: Leverage `astro:assets` with `sharp` for automated WebP/Avif generation.
- **Prefetching**: Enable `prefetch: true` in `astro.config.mjs` for predictive loading.
- **Hybrid Rendering**: Use `output: 'hybrid'` to serve static pages while keeping specific routes dynamic (SSR).

## 🧩 Integration Patterns
- **React/Preact Synergy**: Use Astro as the orchestrator to combine framework-agnostic components.
- **Tailwind Precision**: Scope styles using Astro attributes to avoid CSS bloat.

## 📦 Updatability
This skill is linked to the Astro core and common integrations via `package.json`.
