# Preact Specialist (Level 99)

The art of building high-performance, lightweight web applications with a 3KB alternative to React.

## ⚡ Performance Engineering
- **Bundle Size Optimization**: Leveraging Preact's minimal footprint for mobile-first experiences.
- **Signals**: Using `@preact/signals` for fine-grained reactivity and ultra-low overhead state management.
- **Virtual DOM Efficiency**: Understanding the diffing differences vs. React for better performance.

## 🧩 Compatibility & Integration
- **Preact-Compat**: Strategic usage of the compatibility layer to use React libraries (like Framer Motion) with Preact.
- **Astro Integration**: Using Preact for client-side islands with near-zero hydration cost.

## 🛠️ Tooling
- **Vite Integration**: Optimizing builds with `prefresh` and lightning-fast HMR.

## 📦 Updatability
Tracks the latest Preact core and Signals ecosystem via `package.json`.
