# React Master Architect (Level 99)

Enterprise-grade patterns for building scalable, high-performance React applications.

## 🏗️ Architecture & State
- **Compound Components**: Build flexible, reusable UI components using the `Context API`.
- **Render Props & HOCs**: Mastery of legacy and modern patterns for logic reuse.
- **Server Components (RSC)**: Strategic migration to Next.js App Router patterns to reduce client-side bundle size.

## ⚡ Performance Engineering
- **Memoization**: Surgical use of `useMemo` and `useCallback` to prevent expensive re-renders.
- **Concurrent Mode**: Leveraging `useTransition` and `useDeferredValue` for fluid UI under heavy load.
- **Code Splitting**: Dynamic imports with `React.lazy` and `Suspense` for massive bundle optimization.

## 🧪 Testing & Reliability
- **Testing Library**: Asserting user behavior over implementation details.
- **Zod Integration**: Type-safe data fetching and form validation.
