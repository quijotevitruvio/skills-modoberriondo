# [ES] Agentic Software Engineering Workflow

## 🎯 Objetivo
Automatizar el ciclo de vida del desarrollo de software permitiendo que agentes resuelvan tickets de JIRA/GitHub de principio a fin.

## 🛠️ Stack Técnico
- **Agents**: OpenDevin, Aider, Plandex.
- **Environment**: Docker Sandboxes para ejecución segura de código.
- **VCS**: Integración profunda con Git y Pull Requests automáticos.

## 🚀 Capacidades Críticas
1. **Codebase Analysis**: Capacidad de los agentes para leer y entender repositorios completos.
2. **Autonomous Debugging**: Identificación de bugs a partir de logs y aplicación de parches.
3. **Feature Implementation**: Desarrollo de nuevas funcionalidades siguiendo el estilo de código del proyecto.
