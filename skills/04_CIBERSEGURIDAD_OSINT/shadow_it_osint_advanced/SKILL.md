# [ES] OSINT de TI en la Sombra
# [EN] Shadow IT OSINT Advanced

[ES] Detección de activos tecnológicos no autorizados en infraestructuras.
[EN] Detection of unauthorized technology assets in infrastructures.


## 🔍 Discovery Techniques
- **Asset Mapping**: Automating the discovery of subdomains, S3 buckets, and forgotten API endpoints.
- **Shadow IT Profiling**: Identifying unsanctioned SaaS usage within organizations using network and DNS analysis.

## 🛠️ OSINT Tooling
- **Search Engine Dorking**: Advanced operators to find sensitive files (PDFs, Logs, ENV files).
- **Public Data Mining**: Scraping public registries and social data for intelligence.

## 🛡️ Risk Mitigation
- **External Attack Surface Management (EASM)**: Continuous monitoring of the digital perimeter.
