# [ES] Cross-Platform Ads Attribution Dashboard

## 🎯 Objetivo
Unificar la data de Meta, Google, TikTok y Pinterest en un solo panel para entender el ROAS real y el Customer Journey.

## 🛠️ Stack Técnico
- **Data Collection**: Segment, GTM Server Side.
- **Storage**: BigQuery, Supabase.
- **Visualization**: Grafana, Looker Studio, Streamlit.

## 🚀 Capacidades Críticas
1. **De-duplicación de Conversiones**: Algoritmos para evitar contar una venta dos veces.
2. **Modelos de Atribución**: Last Click, First Click, Linear y Data-Driven.
3. **Alertas de Anomalías**: Notificaciones en Slack/WhatsApp cuando el costo por lead sube fuera de lo normal.
