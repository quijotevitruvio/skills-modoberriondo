# [ES] Dynamic Creative Optimization (DCO)

## 🎯 Objetivo
Generar y optimizar automáticamente miles de variaciones de anuncios (imágenes, videos, copys) basadas en datos de rendimiento en tiempo real.

## 🛠️ Stack Técnico
- **IA Generativa**: ComfyUI (Stable Diffusion), BannerBear API, Shotstack.
- **Ads API**: Facebook Marketing API, Google Ads API.
- **Logic**: n8n para orquestar la generación y subida de creativos.

## 🚀 Capacidades Críticas
1. **A/B Testing Automatizado**: Rotación de creativos basada en CTR y Conversiones.
2. **Personalización Hiper-Local**: Adaptación de anuncios según clima, ubicación o eventos actuales.
3. **Escalado de Formatos**: Transformación automática de creativos para Reels, TikTok, Story y Feed.
