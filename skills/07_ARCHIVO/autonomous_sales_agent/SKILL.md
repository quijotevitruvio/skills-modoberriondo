# [EN] Autonomous Sales Agent

[ES] Prospección y cierre de ventas mediante inteligencia artificial conversacional.
[EN] Prospecting and sales closing via conversational AI.


## 🤖 Agent Personality & Logic
- **Sales Psychology Integration**: Configuring agents with SPIN selling or Challenger Sale frameworks.
- **Objection Handling Matrix**: Pre-defined logic to handle "too expensive", "not now", or "competitor is better" scenarios.

## ⚙️ Tools & Capacities
- **Live Inventory Awareness**: Connecting the agent to WooCommerce/ERP for real-time stock and price quoting.
- **Calendar Integration**: Empowering the agent to book sales calls directly from a conversation.

## 📈 Multi-channel Execution
- **WhatsApp/Chat Persistence**: Maintaining long-term context of the user relationship across multiple sessions.
- **Human Escalation**: Detecting high-intent or complex queries to loop in a human closer via Slack/WhatsApp notifications.
