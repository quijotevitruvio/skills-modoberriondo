# [EN] eBPF Kernel Observability

[ES] Instrumentación y monitoreo profundo a nivel de sistema operativo.
[EN] Deep instrumentation and monitoring at the operating system level.


## 🔬 Kernel Tracing
- **Dynamic Instrumentation**: Using `bpftrace` and `bcc` for real-time, non-intrusive tracing of system calls and kernel functions.
- **Micro-bottleneck Discovery**: Identifying disk I/O, network latency, and mutex contention in production environments.

## 📡 Modern Networking (Cilium)
- **Zero-Trust Networking**: Implementing kernel-level service identity and transparency.
- **XDP Acceleration**: Building ultra-fast network packet filters and load balancers at the network driver level.

## 🛡️ Security Hardened Policies
- **Endpoint Security**: Monitoring file access, process execution, and network connections for anomalous behavior.
- **Runtime Auditing**: Generating granular audit logs for compliance without impacting system performance.
