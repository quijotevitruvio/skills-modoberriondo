# [ES] Ingeniería de Video Programática
# [EN] Programmatic Video Engineering

[ES] Generación dinámica de contenido audiovisual basado en datos.
[EN] Dynamic data-driven audiovisual content generation.


## 🎬 Core Technologies
- **Remotion**: React-based video generation for massive-scale personalization.
- **FFmpeg Mastery**: Command-line orchestration for transcoding, filters, and stream processing.
- **Shotstack / Cloudinary**: Cloud-native APIs for headless video assembly.

## ⚙️ Automated Workflows
- **Dynamic Overlays**: Injecting live data, user handles, or prices into video renders.
- **Programmatic Editing**: Automating transitions, cuts, and audio normalization.
- **High-Scale Rendering**: Using AWS Lambda or serverless GPU clusters for parallel video generation.

## 📦 Use Cases
- Automated social media ads (DCO).
- Personalized customer welcome videos.
- Large-scale educational content generation.
