# Core Web Vitals Optimizer (Level 99)

Mastering the metrics that define user experience and search ranking in the modern web.

## ⚡ The Three Pillars
- **LCP (Largest Contentful Paint)**: Strategies for image preloading, server response (TTFB) optimization, and render-blocking removal.
- **FID/INP (Interaction to Next Paint)**: Minimizing main thread blocking, breaking up long tasks, and optimizing state updates (React/Astro).
- **CLS (Cumulative Layout Shift)**: Aspect-ratio management, reserved space for dynamic content, and font loading strategies.

## 🛠️ Tooling & Auditing
- **CrUX (Chrome User Experience Report)**: Analyzing real-user data.
- **Lighthouse CI**: Automating performance checks in the CI/CD pipeline.
- **Performance Profiling**: Deep-diving into the Chrome DevTools Flame Chart.

## 📦 Updatability
Tracks the latest Google PageSpeed and Lighthouse auditing standards.
