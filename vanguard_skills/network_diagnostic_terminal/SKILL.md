# Network Diagnostic Terminal (Level 99)

The advanced usage of terminal tools for clinical diagnosis of server connectivity, latency, and throughput issues.

## 📡 Connectivity & Discovery
- **`dig` & `nslookup`**: Advanced DNS troubleshooting, recursive lookups, and TTL audits.
- **`nmap`**: Surgical network scanning for open ports, service identification, and vulnerability discovery.
- **`telnet` & `nc` (netcat)**: The "Swiss army knife" for testing port openness and raw data transmission.

## 📈 Latency & Routing
- **`mtr` (My Traceroute)**: Continuous, real-time analysis of packet loss and latency across every hop in the network.
- **`ping` & `curl -w`**: Measuring TTFB (Time To First Byte) and response headers at the terminal level.

## 🛡️ Packet Analysis
- **`tcpdump` & `tshark`**: Capturing and analyzing raw network traffic for protocol-level debugging and security auditing.
- **`netstat` & `ss`**: Monitoring active sockets and resource consumption per service.
